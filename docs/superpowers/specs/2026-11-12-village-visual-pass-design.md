# 파도마을 v0.2 · 시각·조작성 개선 설계

## 의도
현 2.5D 프로토타입은 작동하지만 넓고 단조로운 맵, 비슷한 초록색 타일, 카메라보다 시선을 빼앗는 UI, 서로 다른 스타일의 이모지 도구가 완성도를 깎는다. 남녀노소 즐기는 한국형 따뜻한 바닷마을이 되도록 맵 중심의 화면으로 개선한다.

## 목표
- 기존 저장 데이터 및 생산·건설·배달 규칙을 온전히 보존한다.
- 초행자가 건설 방법을 쉽게 이해하게 한다.
- 고정 투영·동일 광원 방향으로 아틀라스를 그려 건설 도구에도 같은 축소 텍스처를 쓴다.
- 정적 지형과 건물은 캐시하고 최대 3~5개 움직이는 등장인물만 프레임별 그린다.
- 데스크톱/모바일에서 지도, 핵심 자원, 건설도구, 배달에 접근 가능하게 한다.

## 비목표
새 경제 시스템, 신규 자원, 외부 이미지 API, 대규모 렌더러 재작성, 커스텀 백엔드, 다른 게임의 디자인 모사.

## 선택지
1. 기존 CSS만 교체: 빠르나 아트 일관성과 지도의 황량함을 해결 못 함.
2. AI 이미지 텍스처 교체: 감성 변화는 가능하나 등각 축과 투명도 오류 위험 큼.
3. 현재 Canvas 아틀라스를 확장하고 UI 정보량을 재조정: 기존 로직 보존, 비용·위험이 낮고 일관성 확보 가능. **선택.**

## 구조
- `src/render.js`: 아틀라스의 도구 미리보기, 지면·건물의 디테일, 정해진 경로로 걷는 주민/고양이, 초기 카메라 보정.
- `src/main.js`: 미리보기 표시, 도움말/안내와 지도 UI 동작 보정.
- `index.html`, `styles.css`: 정보 위계, 조작 도달성, 한국어 문구, 브레이크포인트.
- `tests`: 기존 게임 규칙 및 브라우저 검증 확장.

## 성공 기준
npm check 통과. 브라우저 상 콘솔 오류 없음. 최초 화면의 마을이 바로 보이고, 모바일에서 도구 선택과 배달이 가능. 아틀라스 프리뷰 미표시 이미지 없음. 실제 측정치 없으면 성능 향상 단언 금지.
