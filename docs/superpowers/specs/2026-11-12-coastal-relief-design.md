# HARBORLINE · 해안 단차와 공간감 (v0.11.0)

## 목적
v0.10 해안은 전체 섬이 같은 높이에 놓인 듯 보인다. 이미 존재하는 등대·주거지·돌길에 더 많은 장식물을 추가하지 않고, 해안에서 땅과 바다 사이의 높이 차이를 읽을 수 있게 한다.

## 비교 및 결정
- 실제 높이 타일·건물 좌표 상향: 물류·배치·카메라·저장 변경과 이전 세이브 회귀 위험이 크므로 제외.
- 신규 풍차 랜드마크: 등대와 기능이 겹치고 넓은 공간을 점유하므로 제외.
- **해안 가장자리에 정적 등각 단차 표현 추가**: 모델을 유지하고 시각적 공간감을 개선하므로 채택.

## 구현 규칙
- src/model.js, src/main.js, 저장 스키마를 변경하지 않는다.
- coastEdgeMask()의 2:1 등각 경계만 이용한다. 뒤쪽 경계는 풀이 얹힌 지형 융기, 앞쪽 경계는 낮은 석재 사면과 물거품을 표현한다.
- 해안 모양은 바람꽃 해안의 확장 상태에서 다시 계산한다.
- 새 스프라이트나 애니메이션 없이 Scene.buildCache()에서만 그린다.
- 건설·산책길·주민·섬 확장 모두 기존 로직을 사용한다.
- 특정 게임 자산은 복제하지 않는다.

## 검증 결과
- Node 37/37 통과 및 Chromium 1365/390/360px 검증.
- 기존 건설·배달·해안 확장 회귀 통과.
- 지도 24×24, 캐시 8,926,848 bytes, 아틀라스 3,409,920 bytes 유지.
- 실기기 장시간 성능과 공개 도메인 직접 브라우저 검증은 별도 과제로 남는다.
