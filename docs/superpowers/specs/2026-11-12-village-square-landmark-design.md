# HARBORLINE · 바람꽃 광장 랜드마크

## 목표와 진단
v0.11에서는 등대가 해안의 상징이지만 마을 중앙의 삼거리는 작은 평면 무늬뿐이다. 건물·재화·퀘스트를 더하는 대신, 기존 길을 마을의 중심으로 읽히게 한다. 한국 바닷마을의 낮은 석재 분수와 바람꽃·청록색 물을 쓰고 타 게임 자산은 모방하지 않는다.

## 선택과 대안
- 새 풍차 건설: 건축 비용, 점유·저장·UI 규칙을 추가해야 해 보류.
- 실제 높이차 시뮬레이션: 투영 좌표와 이동 규칙 변경이 커서 보류.
- 기존 삼거리의 바람꽃 분수: 저장·경제와 무관하며 정적 아틀라스만 사용하므로 채택.

## 동작
- 항구에 연결된 산책길의 3방향 이상 교차점 중 항구에서 가장 가까운 지점 하나만 택한다. 동점은 좌표로 결정한다.
- 도로 위에 낮은 석재 분수, 작은 바람꽃, 물길을 동일한 2:1 등각 투영과 광원 방향으로 표현한다.
- 도로를 철거하거나 연결하면 다음 정적 캐시 재생성에서 자동 갱신된다. 좌표를 점유하지 않고 비용·상태·저장 필드 추가 없음.
- 주민 가림은 기존 규칙을 재사용한다. 매 프레임 새 벡터를 그리지 않는다.
- 24×24, harborline.save.v1, 자원 생산·배달·확장·모바일 조작 불변.

## 검증
Node 선택/단절/복원/불변성; Chromium 1365·390·360px; 기존 게임 시나리오; 캐시와 아틀라스 메모리 및 프레임 중 재빌드 여부.
