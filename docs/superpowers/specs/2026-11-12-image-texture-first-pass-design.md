# HARBORLINE · 첫 PNG 텍스처 전환과 주민 비율 조정

## 배경
기존의 모든 오브젝트가 Canvas 벡터 그래픽으로 생성되어, 집·상점·나무는 조형이 단조롭고 주민의 가시 크기는 건물 대비 과도하다. 작은 연출을 추가해도 시각 품질이 느리게 개선된다는 문제를 해결한다.

## 비교
- 기존 vector paint()를 계속 정교화: 파일은 적지만 이미지 수준의 디테일이 어려움. 제외.
- 모든 타일/오브젝트 동시 교체: 시점 불일치·경계·적응 작업량 과다. 제외.
- **집·빵집·나무만 실제 PNG로 전환하고 주민은 기존 아틀라스 셀을 0.68배 렌더링:** 선택. 그림 품질을 확인하며 점진적으로 확대.

## 설계
- 일관된 온난한 동화풍·상단 좌측 광원·반고정 등각 시점 이미지 3개를 144×148 PNG 셀로 준비한다. 생성된 아트 시안에서 개체를 분리·마스킹한 첫 자산이며 향후 정식 3/4 제작 규격으로 교체 가능하다.
- 집·빵집·나무의 텍스처는 정적 캔버스 아틀라스에 덮어 그린다. 프로시저럴 셀은 이미지 로드 실패 시 폴백으로 유지한다.
- 모든 파일이 로드되면 한 번만 정적 맵 캐시를 무효화하고 건설 메뉴 미리보기도 갱신한다. 프레임마다 별도 Image.drawImage를 추가하지 않는다.
- 주민 둘 0.68x, 고양이 0.75x로 출력한다. 이미지 자체와 바닥 앵커는 유지하며 `spriteDestination`에서 발 접지를 고정한다.
- 모델/경제/지형/세이브 v1 호환 유지. 이미지 생성/배치 외 새 기능 추가 없음.

## 테스트
Node: 정확한 파일명·PNG 규격·렌더 앵커/스케일. Chromium HTTP PC/390/360: 이미지 로드 확인, 실제 아틀라스 픽셀 변화, 프레임간 캐시 재사용, 건설/배달/모바일 입력 및 리소스 로드 실패 폴백.

## 리스크
- 이미지 생성기가 시점을 제각각 만들거나 배경을 남길 수 있다. 반드시 투명 배경/경계/각도를 렌더링 캡처로 검수한다.
- 기존 세이브 키와 모델 코드는 수정하지 않는다.
