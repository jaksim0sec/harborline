# HARBORLINE v0.6 · 첫 5분의 선택과 목표

## 의도
처음 시작한 플레이어가 1분 안에 편지 목표를 이해하고, 도움 요청이 실제로 얼마나 생산을 앞당기는지 판단하여 배달의 성과를 경험할 수 있게 한다.

## 확인된 문제
- 현재 `renderHUD`는 재고와 부족량만 보여 주고, 기다릴 기간과 도움의 가치가 표현되지 않는다.
- 기존 안내 카드는 건설 방법만 설명하고 현재 게임 상태에 따른 다음 행동으로 연결되지 않는다. 930px 이하에서는 안내가 완전히 숨겨진다.
- 첫 배달 보상과 이후 축제까지의 진행은 정적 텍스트에 묻힌다.

## 비교한 접근
1. 신규 튜토리얼·퀘스트 시스템: 구현은 가능하지만 기존 보상 및 저장 구조를 복잡하게 한다. 제외.
2. 현실 시간 제한 배송: 선택을 강제하고 아늑한 마을 철학과 충돌한다. 제외.
3. **현재 시뮬레이션에 기반한 예상 완료일과 상태별 작은 다음 행동 안내**: 선택 결과를 보여 주되 새 경제 요소는 만들지 않는다. 채택.

## 설계
- `model.js`에 순수 함수 `forecastOrder(game, id, focusId=game.focusOrderId, maxDays=30)`를 제공한다. 현재 생산 규칙으로 복제 상태를 최대 30일 미리 계산하여 주문을 충족할 일수 또는 null을 반환한다. 원본 상태는 절대 변경하지 않는다.
- `nextStep(game)`은 즉시 배달할 수 있는 편지가 있으면 먼저 그것을 제안한다. 없으면 가장 큰 단축 효과가 있는 편지를 표시하고, 이미 도움을 선택한 상태라면 남은 예상일을 안내한다. 일할 시설이 끊겨 있으면 산책길 연결을 우선 안내한다. 여섯 번째 배달 이후에는 축하 메시지로 바꾼다.
- 기존 안내 카드를 가벼운 상태형 카드로 바꾸고 PC와 모바일에서 배달 열기 등의 기존 행동만 연결한다. 신규 모달·새 내비게이션·신규 저장 필드는 없다.
- 편지 목록의 기존 정보에 작은 한 줄의 예상 일수를 추가한다. 예측은 현재 건물/자원/선택 기준이며 게임 상태가 바뀌면 갱신한다.
- `render.js`의 색감과 인물 비율은 다음 별도 아트 단계로 미룬다. 섬 확장은 새로운 지형 데이터와 저장 마이그레이션이 필요하므로 이번 단위에는 포함하지 않는다.

## 완료 기준
- 초기 상태: 햇밀 편지에 도움을 주면 완료 예상이 4일→2일로 바뀐다.
- 재고가 충분하면 즉시 배달 안내, 생산시설이 끊기면 연결 안내, 축제 이후에는 자유롭게 꾸미기 안내.
- 저장 키는 `harborline.save.v1`; 모든 기존 테스트 통과. PC와 390/360px Chromium 렌더·조작 재확인.
- 검증 결과만 GitHub `main` 단일 커밋, Vercel Production 상태/SHA 확인.
