# HARBORLINE · 거리와 건축물의 깊이감 (v0.10.0)

## 배경
v0.9.0은 돌길/광장으로 마을 연결감을 높였으나, 건물 입면이 단색이고 지붕/기단/그늘의 층위가 부족하다. 바다-땅 사이에서도 물가의 높이와 깊이가 드러나지 않는다. 무엇보다 주민을 캐시 완성 후 그려 나무/건물과의 전후 관계가 틀어진다.

## 접근 비교
1. 모든 오브젝트를 매 프레임 깊이 정렬해 다시 그림: 가림은 정확하지만 정적 캐시 포기, 비용 증가.
2. 3D 실시간 메시/동적 광원: 현 코드와 저장/성능 제약에 비례하지 않는 재작성.
3. **기존 정적 아틀라스 강화 + 해안선 정적 캐시 + 움직이는 주민만 가림 오브젝트 국소 재그리기: 채택.** 렌더링 캐시를 유지하면서 시각적 깊이를 보완한다.

## 요구
- 집/빵집/공방/항구 건물의 벽면, 지붕, 기단에 동일 등각 투영과 상단 왼쪽 채광 규칙 적용. 각 건물 아이덴티티 보존.
- 나무 그림자/수관 다층화, 잔디와 해안선에 적정한 명암 대비. 거친 경계선이나 타일 단위 경계의 무리한 장식 금지.
- 물가 모래 타일의 물 접한 모서리만 윤곽/잔물결 표기. 고정 캐시에서만 계산.
- 주민이 큰 건물/나무 뒤를 통과하면 해당 시야 가림만 되살림. 정적 배경 전체의 프레임별 재렌더 금지.
- 모델, 세이브, 길 연결, 건설, 배달, 카메라/터치 입력 변경 금지. 아틀라스 패키지 유지.

## 검증
- Node: 해안 모서리 판정 및 움직이는 주민 가림 판정, 기존 34건 회귀.
- Chromium: 정적 캐시 재사용/카메라/조작/360·390·1365px 화면, 전후 이미지.
- 변경 파일만 단일 GitHub 커밋, Vercel Production 동일 SHA 확인.

## 한계
- 입체감은 2.5D 그림자·명암·겹침 표현이며 진짜 고저차 지형이나 카메라 회전은 포함하지 않음.
- 몬드의 특정 구조물/에셋을 그대로 재현하지 않음.
