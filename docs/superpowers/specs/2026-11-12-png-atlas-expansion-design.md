# HARBORLINE · 그림 같은 바닷마을 PNG 아틀라스 2차

## 문제
v0.14 집·빵집·수목만 이미지라 항구·농장·공방·잔디가 도형으로 튀어 보인다. 확대/축소 시 객체의 투영·바닥 접점과 타일 격자 연결이 중요하다.

## 선택한 접근
1. 24×24 지도와 기존 아틀라스를 유지한다. 3종 객체의 동일한 아트 연구 시안에서 분리한 PNG를 144×148 규격으로 리샘플링하고 발/건축 바닥을 (72,103)에 둔다.
2. 이미지로 전체 잔디 타일을 완전히 덮으면 경계가 과도하게 생기는 문제가 실제 PC 캡처에서 나타났다. 최종 구현은 **절차적 지형 상단에 투명 래스터 디테일 PNG를 합성**하여 경계를 보존한다.
3. 독립적인 가상 텍스처 페이지나 게임 상태·재화·새 빌드 타입은 추가하지 않는다. 기존 실패 셀만 절차 그림으로 복구한다.

## 비교한 대안
- 맵과 자산 전체 AI 생성 후 아틀라스 교체: 통일된 2:1 각도, 바닥 기준점 보장이 어려우므로 거부.
- 모든 PNG를 drawImage로 매 프레임 별도 렌더: 프레임 부담 증가로 거부.
- 현재 144×148 셀에 7 PNG 교체/오버레이 (채택): 검증 범위 최소, 기존 저장 보존.

## 수락 조건
- PNG 7종이 실제 파일이며 RGBA/144×148, 3종 객체 접지 하단 103px.
- 4종 잔디 오버레이는 원래 절차적 타일을 보존하고 무늬만 추가.
- PC 1365px, 모바일 390/360에서 기존 조작, 로드 실패 복구, 주민 크기(0.68배) 실측/검토.
- Node·전체 Chromium 회귀·저장 v1·캐시 크기 확인.
- 원격 변경은 기존 SHA 확인 후 단일 GitHub commit, Vercel Production SHA 일치 확인.

## 명시적 미포함
- 실기기 장시간 메모리·배터리, 전 지역 아트 교체, 삼차원 카메라 회전, 실제 농업 생산 애니메이션.
