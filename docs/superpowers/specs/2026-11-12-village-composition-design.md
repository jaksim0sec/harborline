# 파도마을 v0.9 · 마을 조형의 일체감

## 목적
v0.8의 기능들은 동작하지만 마을이 단절된 돌판 위의 건물·랜덤한 수풀처럼 보인다. 푸른 들판, 돌길, 건물, 작은 마당이 연속되는 한국어권의 아늑한 해변 마을로 개선한다. 몬드의 *초원/건축 색 대비와 광장 중심의 구성*만 참고하며 건물이나 문양을 복제하지 않는다.

## 문제 근거
- `render.js`의 road atlas는 모든 방향에 동일한 단독 다이아몬드만 사용하고 있어 인접 도로가 연결되어 보이지 않는다.
- 자생 수풀 배치가 전역 해시 중심이라 주민 생활권과 경관의 연결이 약하다.
- 건물의 지붕/외벽 색이 생활 구역 안에서도 서로 분리돼 보인다.

## 접근 비교
1. 전체 맵 데이터 재배치 + 건물 이동: 기존 v1 저장과 경로를 망가뜨림. 제외.
2. UI/경제에 광장 건물 추가: 새 플레이 규칙을 쓸 이유가 없음. 제외.
3. **기존 길 연결 데이터로 텍스처를 자동 선택하고, 갈림길에 소형 포장광장·생활권 꽃과 수풀·따뜻한 건축 색을 연출**: 선택.

## 범위 및 인터페이스
- `src/render.js` 내 모든 변형은 기존 정적 캐시 아틀라스 단계에서 완성된다. 프레임별 벡터 렌더링을 추가하지 않는다.
- `roadMask(roadSet,x,y)`는 동일 도로 좌표로 N/E/S/W 4비트 조합을 반환한다. 비트 순서 +x=2, -x=1, +y=8, -y=4로 고정한다. 길 16종을 아틀라스로 만든다.
- 세 갈래 이상 길이 만나는 부분은 같은 한 타일 위에 별도 건설 불가 건물 없이 작은 광장 포장으로 렌더한다.
- `sceneryAt(game,x,y,used)`는 건물이 차지하지 않는 땅에서만 결정론적으로 생활권 식재를 선택한다. 모든 객체는 지금의 등각 투영, 정렬 순서, 텍스처 캐시를 유지한다.
- 기존 `terrain`, `isLand`, `connections`, `roadToBuilding` 등의 모델 코드는 건드리지 않는다.
- v1 데이터·게임 경제·건설 판정·카메라·도구·모바일 상호작용 모두 그대로 유지한다.
- 과도한 꽃/바위 배치, 텍스처 단절, 길·건물 접점 그림자, 작은 화면 가시성 확인.

## 완료 조건
- 새 T자 교차로에서도 포장 광장이 자동으로 생기고, 길 철거 시 다시 일반 길로 돌아간다.
- 길 아틀라스 변형은 같은 인접 도로 집합에 대해 항상 같은 결과를 만들고, 건물·도로 좌표를 바꾸지 않는다.
- Node 회귀 + Chromium PC/390/360 실제 렌더·건설·철거·배달·확장 시각 확인.
- 단일 원격 커밋, Vercel Production 배포 SHA 검증. 불가 사항은 숨기지 않는다.
