# 파도마을 시각 개선 구현 계획

- 설계: `docs/superpowers/specs/2026-11-12-village-visual-pass-design.md`
- 지침: `AGENTS.md`.
- 작업 단위: ① 일관된 아틀라스/카메라 ② 렌더링 경량 애니메이션 ③ UI 정보 밀도 및 모바일 접근성 ④ 브라우저 회귀검증.
- 사용자에게 디자인 승인을 재요구하지 않음: 이번 실험에서는 명시적으로 자율 판단을 위임했음.

## 1. 일관된 아트와 지도 카메라
- 대상: `src/render.js`, `tests`.
- RED: 동등한 스프라이트 미리보기 생성, 실제 캔버스 좌표 계산과 렌더의 일치 확인 추가.
- GREEN: 프리뷰 캔버스의 잘린 범위·높이를 균일하게 제공, 지형과 건물 명암 보정, 초기 구도 보정.
- 검증: Node 게임 테스트, 브라우저 캡처/스크린 위치 테스트.

## 2. 움직임
- 대상: `src/render.js`, `tests`.
- RED: 인물 위치 계산 순수 함수의 시간/정지 프레임 및 범위 테스트.
- GREEN: 캐시된 미니어처 캐릭터 텍스처를 이용하는 주민, 고양이, 파도 애니메이션.
- 검증: 테스트/프레임 비용 측정, JS 오류 확인.

## 3. UI 재구성
- 대상: `index.html`, `styles.css`, `src/main.js`.
- RED: 모바일에서 화면 외의 도구 탐색, 배달 열기와 선택 상태를 브라우저 테스트로 보장.
- GREEN: 이모지 중심 메뉴를 아틀라스 썸네일로 바꾸고 배달 패널/메뉴 높이를 줄여 지도 중심으로 재정렬.
- 검증: 데스크톱 1365×820, 모바일 390×844, 360×740에서 화면 확인.

## 4. 통합 및 배포
- `npm run check` 및 브라우저 E2E 실행, 기존 저장 상태 유지 확인.
- 필요한 파일만 Github 단일 검증 커밋, Vercel 배포 확인. 배포 실패 시 성공 주장 금지.
